# FixTrail AI 🚀

**AI-Powered Issue Reporting and Tracking Platform**

## 📌 About the Project

FixTrail AI is a smart web application designed to help people report problems, track their progress, and manage issues efficiently. The platform aims to make issue reporting easier, faster, and more transparent through a simple and user-friendly interface.

## 🎯 Problem Statement

Many people face difficulties when reporting problems and tracking whether they have been resolved. Traditional reporting methods can lack transparency, clear status updates, and an organized tracking process.

FixTrail AI aims to simplify this process by providing a centralized platform for reporting and tracking issues.

## 💡 Proposed Solution

FixTrail AI provides a digital platform where users can submit issues and follow their progress. The project is designed to improve accessibility, organization, and transparency in issue management.

## ✨ Key Features

- 📝 **Issue Reporting:** Submit problems through a digital platform.
- 🔎 **Issue Tracking:** Follow the status of reported issues.
- 📊 **Status Monitoring:** Organize issues based on their progress.
- 🤖 **AI Integration:** Designed to support intelligent issue analysis and prioritization.
- 💻 **User-Friendly Interface:** Simple and accessible web experience.
- ⚡ **Centralized Management:** Keep issue information organized in one place.

*Note: Features may depend on the current implementation of the application.*

## 🛠️ Technologies Used

- **Frontend:** Next.js, React, TypeScript
- **Development Environment:** Visual Studio Code
- **Database and Backend Services:** Supabase
- **Styling:** CSS and project-specific UI components
- **Package Management:** npm
- **Development Server:** Next.js with Turbopack

## ⚙️ Installation and Setup

### Prerequisites

Install the following tools before running the project:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/)

### Step 1: Clone the Repository

```bash
git clone https://github.com/JayabalaArunasubha/FixTrail.git
```

### Step 2: Open the Project Folder

```bash
cd FixTrail
```

If the application files are inside a nested `FixTrail AI` folder, navigate into that folder before continuing.

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Configure Environment Variables

Check the `.env.example` file and configure the required environment variables in a local `.env.local` file.

Add the necessary Supabase configuration values if the application requires them. Never publish private API keys, passwords, or secrets.

### Step 5: Start the Development Server

```bash
npm run dev
```

### Step 6: Open the Application

Visit the following URL in your browser:

http://localhost:3000
